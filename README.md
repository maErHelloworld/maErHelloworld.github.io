# Martim F. Pinto — Personal Portfolio

Bem-vindo ao repositório do meu site/portfólio pessoal ([martimfpinto.pt](https://martimfpinto.pt)). Este projeto reflete o meu percurso multidisciplinar em **Product Management / Ownership**, **Desenvolvimento de Software (Mobile/Web)** e **Fotografia Profissional**.

---

## Destaques do Projeto

- **Design Dark & Beige:** Estética moderna, limpa e executiva com tema escuro e apontamentos em tom bege/dourado.
- **Animações & Micro-Interações:** Animações de scroll integradas com `ScrollReveal.js`.
- **Feed do Instagram Vivo:** Integração dinâmica através do widget `Behold.so`.
- **Galeria de Fotografia:** Exibição responsiva de trabalhos visuais com embed do `Juicer.io`.
- **Página 404 Personalizada:** Página de erro nativa configurada para o GitHub Pages.

---

## Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript / TypeScript
- **Bibliotecas & Scripts:** 
  - [ScrollReveal.js](https://scrollrevealjs.org/) (Animações de entrada)
  - [FontAwesome](https://fontawesome.com/) (Iconografia)
  - [Behold.so](https://behold.so/) (Widget de Instagram)
  - [Juicer.io](https://www.juicer.io/) (Galeria externa)
- **Formulários:** Formspree (Processamento de contacto)
- **Alojamento:** GitHub Pages
